# ЭкоСознание

Экология как способ смотреть на реальность. Статичный сайт: 17 разделов, 19 эссе и 9 лабораторий о связях между едой, архитектурой, психологией, наукой и планетой.

## Как опубликовать через GitHub Pages

Проект — обычный статичный сайт, состоит только из HTML. Готов к деплою «как есть».

### 1. Создать репозиторий на GitHub

- Зайти на https://github.com → «New repository»
- Название: например, `ecosoznanie` (можно любое)
- Публичный (Public) — обязательно для бесплатного GitHub Pages
- Не добавлять README, .gitignore, LICENSE — они уже есть в архиве
- Нажать «Create repository»

### 2. Загрузить файлы (проще всего — через веб-интерфейс)

- На странице пустого репозитория нажать ссылку «uploading an existing file»
- Перетащить **все файлы** из архива (не саму папку `ecosoznanie_v3`, а её содержимое)
- Внизу — «Commit changes»

### 3. Включить GitHub Pages

- В репозитории: `Settings` → `Pages` (в боковом меню слева)
- В «Source» выбрать `Deploy from a branch`
- В «Branch» выбрать `main` и папку `/ (root)` → `Save`
- Через 1–2 минуты сайт будет доступен по адресу:
  ```
  https://ТВОЙ_НИК.github.io/ecosoznanie/
  ```

### 4. (Опционально) Свой домен

- В `Settings` → `Pages` → `Custom domain` можно указать свой домен
- Понадобится настроить DNS-запись CNAME у регистратора

## Структура

- **`index.html`** — главная страница (сюда попадаешь по корневому URL)
- **`section-*.html`** (17 файлов) — разделы: Философия, Экономика, Наука, Психология, Еда, Архитектура и др.
- **`essay-*.html`** (19 файлов) — эссе
- **`lab-*.html`** (9 файлов) — лаборатории (диалоги-мысленные эксперименты)
- **`about.html`**, **`map.html`** — служебные страницы
- **`.nojekyll`** — говорит GitHub Pages не запускать Jekyll (у нас чистый HTML)
